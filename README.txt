منصة الاشتراك التجريبية — ملفات التشغيل

المحتويات:
- index.html: صفحة عربية متجاوبة، باقات اشتراك، محاكاة إدخال بيانات دفع تجريبية، OTP ثابت تجريبي، استبيان.
- Code.gs: يستقبل أحداث الاستخدام والاستبيان ويرسلها إلى Telegram.
- لا تجمع الصفحة أو ترسل أرقام بطاقات أو CVV أو رموز OTP. القيم التجريبية ثابتة ومحددة داخل الصفحة:
  TEST-CARD / 12/30 / 000 / 123456

1) تخصيص الموقع
- افتح index.html.
- استبدل YOUR BRAND باسم المشروع.
- عدّل أسعار وأسماء الباقات والنصوص حسب دراستك.
- ارفع index.html إلى جذر مستودع GitHub.
- فعّل Settings > Pages > Deploy from a branch > main > /(root).

2) إعداد Telegram
- افتح Telegram وابحث عن @BotFather.
- أرسل /newbot واتبع التعليمات، ثم احتفظ بالرمز سرياً.
- ابدأ محادثة مع البوت وأرسل له رسالة.
- للحصول على chat id افتح:
  https://api.telegram.org/botYOUR_TOKEN/getUpdates
  استبدل YOUR_TOKEN برمزك، واقرأ message.chat.id.
- لا تشارك رابط getUpdates أو رمز البوت مع أي شخص.

3) إعداد Google Apps Script
- افتح https://script.google.com وأنشئ مشروعاً.
- الصق Code.gs واحفظ.
- Project Settings > Script Properties: أضف TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID.
- Deploy > New deployment > Web app.
- Execute as: Me.
- Who has access: Anyone.
- Deploy ووافق على الأذونات، ثم انسخ رابط Web app الذي ينتهي بـ /exec.

4) ربط الصفحة
- في index.html ابحث عن:
  const REPORT_ENDPOINT = "ضع_رابط_Apps_Script_هنا";
- ضع رابط Web App داخل علامات الاقتباس.
- احفظ الملف وارفع التعديل إلى GitHub.

ماذا يصل إلى Telegram؟
- اختيار الباقة.
- إكمال حقول الدفع التجريبية (حدث فقط، لا تصل القيم المدخلة).
- إكمال رمز التحقق التجريبي (حدث فقط، لا يصل الرمز).
- نوع الجهاز، مدة المراحل، إجابات الاستبيان وملاحظاته.

تنبيهات:
- هذه تجربة بحثية وليست خدمة دفع. لا تستخدم بيانات بطاقات أو OTP حقيقية.
- لا تضع رمز Telegram في index.html.
- لا تجمع بيانات تعريفية غير ضرورية. أضف توضيحاً للمشاركين عن البيانات البحثية التي تسجلها.
- Apps Script endpoint عام؛ هذه النسخة مناسبة لاختبار محدود. قبل نشرها على نطاق واسع، أضف وسائل منع إساءة الاستخدام ومراجعة الخصوصية.
- الأسعار افتراضية، ولا يحدث أي خصم أو اشتراك فعلي.
